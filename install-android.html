⚙️ Requirements

  • Android 5.0+ (Lollipop or higher)
  • Chrome for Android (Version 61+, recommended: latest version)
  • USB OTG adapter or USB-C to USB-A cable
  • ESP32 or ESP8266 device

📋 Installation Guide

1

Open Chrome

Open this page in Chrome for Android (not Firefox or Samsung Internet)

2

Navigate to main page

Click the button below to go to the WebSerial ESPTool app

🚀 Open WebSerial ESPTool
3

Install app

Tap the menu (⋮) in the top right and select "Add to Home screen" or "Install app"

4

Confirm installation

Confirm the installation. The app will appear on your home screen

5

Connect ESP device

Connect your ESP32/ESP8266 via USB OTG adapter to your Android device

6

Grant USB permission

Click "Connect" in the app and select your ESP device. Allow USB access when prompted

💡 Tip: The app works without installation directly in the browser. However, installation provides a better app experience and offline functionality.
⚠️ Important: WebUSB only works with USB OTG (On-The-Go). Make sure your Android device supports USB Host Mode.

🎯 Getting Started

Flash firmware

Select a .bin file, enter the offset (e.g. 0x0 for bootloader) and click "Program"

Read partition table

Click "Read Partition Table" to view the flash memory layout

Read flash

Enter address and size and click "Read Flash" to read the memory
